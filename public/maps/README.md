# Map Images

Place 2048x2048 (or 1024x1024) PNG minimap images here, named exactly:

- `Erangel.png`
- `Miramar.png`
- `Taego.png`
- `Vikendi.png`

Sources:
- PUBG Media Kit: https://www.pubg.com/en/game/maps
- PUBG Wiki (community): https://pubg.fandom.com

The map image (0,0) top-left must correspond to game coordinate (x=0, y=mapSize)
i.e. the northwest corner. Most official PUBG minimaps are oriented this way.

If images are missing, the app renders a grey fallback with an error label.
